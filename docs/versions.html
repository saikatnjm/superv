Release history

Stable versions

Click a version to see what it has and its downloads. Prebuilt packages are for 64-bit PCs (x86_64); on anything else, build from the source archive.

  1. 2.0.0

    LatestMajor    Clipboard and emoji for Linux. The Win+. emoji panel, until now the separate app SuperDot, joins SuperV: one program, one background process, both panels.

    New

    • Emoji panel on Super+.: emoji, kaomoji and symbols, search, recently used, skin tones; typed where you were writing, your clipboard put back
    • Settings switch for the emoji panel. Off, it isn't loaded at all (about 5 MB of memory instead of 11) and Super+. goes back to your desktop
    • ☺ and 📋 buttons to switch between the two panels, like Windows 11
    • Replaces SuperDot and brings its settings and recently used emoji along
    • superv --emoji with --tab, --search and --insert
    • This versions page, a changelog, contributor guide, security policy and automatic build checks

    Still missing

    • Paste as plain text, colour picker, copy text from the screen (planned for 2.1)
    • KDE Plasma clipboard shortcut is still experimental
    • On Sway, Hyprland, i3 and COSMIC you add the two shortcut lines yourself
    .deb Ubuntu · Mint · Debian .rpm Fedora · openSUSE .pkg.tar.zst Arch source release notes ↗ Ubuntu 22.04+ · Mint 21+ · Debian 12+

  2. 1.2.3

    Last 1.x    The final version of SuperV 1: the clipboard panel only, with every 1.x fix.

    Has

    • Clipboard history on Super+V: last 25 texts and images, click to paste, pin, clear on reboot
    • Own shortcut, System/Light/Dark theme, text size, movable panel
    • Packages for Ubuntu, Mint, Debian, Fedora, openSUSE and Arch; PPA with updates
    • Restarts itself after an update

    Still missing

    • No emoji panel (it was the separate SuperDot app)
    • No way to turn features off besides clipboard history itself

  3. SuperDot 1.0.0

    Merged into 2.0    The Win+. emoji panel as its own app. Everything it did is in SuperV 2.0, which replaces it when installed.

    Had

    • Emoji, Kaomoji and Symbols tabs on Super+., typed for you
    • Glass look, six colour palettes, skin tones, recently used

    Lacked

    • A second app and background process next to SuperV
    • No clipboard history; no way to switch to it

Older versions

Installing an older version

Install it

Download the package above and install it as usual. On Ubuntu and Mint: sudo apt install --allow-downgrades ./superv_1.2.3_amd64.deb. SuperV restarts into it by itself.

Keep it

Using the PPA? Stop it updating SuperV again with sudo apt-mark hold superv; sudo apt-mark unhold superv undoes that. Fedora: sudo dnf versionlock add superv.

Going back from 2.0 to 1.x

First turn off Emoji panel in the settings (Super+V → ⚙), so Super+. goes back to your desktop. Your clipboard history and settings work in every version.
